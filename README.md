# harkinianpad

Investigation and planning for a native iOS/iPadOS build of Ship of Harkinian
(The Legend of Zelda: Ocarina of Time PC port) on top of libultraship.

See `ios-feasibility-and-implementation-plan.md` on the
`claude/libultraship-ios-feasibility-iw6grt` branch (PR #1) for the
feasibility investigation and implementation plan.
